# Curatorial Structure Proposal — munzbjos.github.io Redesign

## 1. Curatorial goal

The redesigned website should present Josef Münzberger primarily as a **cartographer, researcher and educator**, with a strong emphasis on thematic cartography, spatial data visualization, interactive storytelling and historical cartography.

The website should feel like a curated portfolio rather than an archive. The visual language should be minimal, image-led and editorial, inspired by contemporary design portfolios such as Sacha Schlumpf’s website, while retaining an independent identity.

Key principle:

> **Show fewer words, stronger visuals, and clear project hierarchy.**

---

## 9. Visual grid principles

### Desktop

Recommended:
- editorial CSS grid
- two or three columns depending on viewport
- selected projects may span two columns
- no rigid card boxes
- no shadows unless extremely subtle
- generous white space

### Mobile

- one-column layout
- full-width project covers
- same content hierarchy

### Tile styling

Prefer:
- image
- title
- minimal metadata

Avoid:
- visible borders around every card
- excessive hover animation
- paragraphs inside grid tiles
- badges for every keyword
- developer-portfolio visual clichés

### Motion

Use only subtle motion:
- image scale / crop shift
- text reveal
- smooth page transitions

Respect:
`prefers-reduced-motion`

---

## 10. Media strategy

For every project define:

- **cover** — main grid image
- **gallery** — selected detail images
- **interactive output** — external or embedded only where useful

Do not use live embeds inside the Work or Research grids.

Use static covers for:
- ArcGIS StoryMaps
- Sketchfab
- other interactive outputs

Interactive embeds may appear on detail pages.

---

## 11. Detail page hierarchy

Recommended project detail template:

1. Title
2. Year / project period
3. One-line project type
4. Large hero image
5. Short description
6. Selected visuals
7. Role / tools / methods
8. Publication or interactive output, if relevant
9. Related project / next project navigation

Keep detail pages visually led.

Avoid:
- long unbroken text
- academic abstract structure
- large metadata tables

## 15. Overall recommendation

The redesigned site should not try to document everything Josef has ever done.

It should communicate three things quickly:

1. **strong thematic cartography and visual design**
2. **active research in spatial visualization and historical cartography**
3. **breadth across interactive storytelling, coding, teaching and 3D work**

The site should therefore behave as a **curated visual portfolio with a research layer**, rather than as an academic CV converted into a website.
